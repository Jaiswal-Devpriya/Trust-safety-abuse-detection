# Trust Safety Abuse Detection

LLM-powered content moderation and abuse signal detection pipeline built using Python, OpenAI GPT-4, and Streamlit.

## Overview

This project simulates a production Trust & Safety workflow by automatically classifying user-generated content into abuse categories, validating model outputs, generating abuse signals, and surfacing moderation insights through an interactive dashboard.

## Features

* Toxic content classification using GPT-4
* Multi-label abuse detection
* Prompt-engineered moderation workflows
* Automated data validation and schema enforcement
* Signal scoring and prioritization
* Streamlit analytics dashboard
* Trend monitoring and moderation reporting

## Tech Stack

* Python
* OpenAI GPT-4
* Pandas
* Pydantic
* Streamlit
* Git/GitHub
